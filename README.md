"The Stop" — a short poem about agency: the power to stop and to stay. Halfway through saying yes, the speaker stops — not a door slamming, but a hand, mid-air, choosing the rail instead — and the yes stays unspoken, and mine.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), 211 characters, deterministic, standard library only, no network.
